在浏览器里上传本地视频，按时间戳切出 5 到 60 秒片段，预览和下载。无需安装 Python 或 FFmpeg。这不是 X 官方产品，切出来的是普通 MP4，不会自动带「Clip from」署名。官方剪辑仍须在手机 App 里完成。

把视频拖到这里，或点「选择视频」。支持常见的 MP4、WebM 等格式。
文件只会留在这台电脑的浏览器里，不会上传到服务器。

请只处理你有权使用、或准备引用原作者的视频。加载示例只会填入时间戳，仍需你自己上传原片。
