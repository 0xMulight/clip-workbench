片段工作台 · Windows 10/11 x64 一键包

1. 下载 clip-workbench-windows-x64.zip。
2. 右键 ZIP →「全部解压」，解压到桌面或文档目录。不要在压缩包预览里双击。
3. 打开解压后的文件夹，双击「启动片段工作台.bat」。
4. 浏览器会自动打开 http://127.0.0.1:8765/；没自动打开时，可复制此地址到浏览器。
5. 粘贴带视频的 x.com / twitter.com 帖子链接。
6. 导入亮点配方（JSON 或简单文本），然后点「拉取并拼接」。例如：
   08:50-09:49 镜像猎杀
   2:28 3:28 成绩单
7. 预览并下载拼接片，单段也能单独下载。

不需要安装 Python 或 FFmpeg，不需要改 PATH，不需要管理员权限。
运行时请保留黑色窗口，关闭窗口即停止。源视频和结果在 work 目录内。
程序只监听 127.0.0.1；不会对局域网或公网提供下载服务。
需要网络来下载原帖视频；仅支持你能合法访问、且提取器支持的帖子。
有些帖子需要登录或有地区限制，不保证每条都能下载。不要公开分享 cookies 或凭据。

下载组件更新：
先关闭工作台窗口，再双击「更新下载组件.bat」。只更新此文件夹内的 yt-dlp。
更新器从 PyPI 官方下载纯 Python wheel，并核对 PyPI 公布的 SHA256。
若新版需要更高 Python 版本，请重新下载新版完整一键包。

常见问题：
- SmartScreen：此开源包未做代码签名。如被拦截，请先核对下载地址与 SHA256；
  确认可信后可点「更多信息」→「仍要运行」。不要关闭系统安全保护。
- 防火墙：本工具只在本机使用，一般无需放行；如弹窗，最多仅允许专用网络，勿允许公用网络。
- 端口 8765 被占用：已有工作台时直接访问上述网址；否则关闭占用该端口的程序。
- 文件不全/临时目录：重新右键 ZIP →「全部解压」。安全软件若隔离组件，请先核对来源。
- 网络问题/下载失败：先试更新下载组件。帖子可能已经删除、不含视频或访问受限。
- 启动失败：如生成 startup-error.log，可用记事本查看，不要公开贴出隐私信息。
